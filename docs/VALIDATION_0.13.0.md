# 0.13.0 本地验证

Blender 5.1.2，2026-09-12。新增人物部件候选识别、预览和副本分离。

## 真实模型

使用玛丽独立人物的只读源文件，31,858 顶点、65 个形态键。自动候选分出身体、头发、服装、左右鞋袜、下装和饰品；低把握的袜子、下装及头饰保留问号提示。检查了正面全身彩色渲染，鞋袜、短裤与上衣分开，发带/花饰/飘带归入饰品。

默认勾选服装和左右鞋，生成四个对象及四个部件子集合，包括未分离剩余网格。每个对象均保留 65 个形态键；全部面恰好出现一次。顶点、形态键坐标、UV、权重、材质与骨架绑定检查通过。自定义法线恢复后最大向量误差约 0.000689（约 0.0395°），低于 0.001 上限。

已验证彩色预览关闭、原模型/结果切换、保存重开后的分组与预览可用，以及分离结果不与原模型/预览重叠。源文件 SHA256 未变化；FPS、帧范围、Action 数与物理烘焙状态保持原值。

## 合成模型与失败路径

- 多个不相连衣袖/衣身归同组，不同材质的鞋面、鞋底、鞋带归入左右鞋；陌生独立物件保留待识别。
- 共享网格使用者和对象级材质槽不变，反复预览清理后对象、网格、材质、Action 数量无增长。
- 手动补选/取消误选后替换分组，未选中的旧成员回到待识别。
- 源坐标变动时拒绝旧分组，注入验证失败后清理本轮副本，不改变原数据。
- 相对形态键 Action、自引用驱动及骨架变形在三个帧上的实际顶点差为 0；简单形态键 NLA 链接保留。
- 同一衣服跨两个源网格时保留两套不同形态键，归入同一部件集合。
- 不支持的活动修改器明确停止；注册/卸载循环通过。

已有道具接触回归通过：持握变换误差 0、模糊槽位回滚和分数 FPS 保留。旧资源、物理和渲染规划操作符仍可注册。
