# BA Animation Workflow 0.10.0 使用说明

## 安装与入口

使用本仓库 `dist/ba_animation_workflow-0.10.0.zip`，在 Blender 5.1 的偏好设置中从磁盘安装并启用。面板位于 `N → BA 动画`。Motion Bridge 使用它自己的仓库和安装包。旧整套配置安装器已停用，避免还原旧版本或覆盖用户偏好。

## 一段动作的制作

1. 选择角色和动作文本块，每个文本只放一段英文动作提示。
2. 设置本 Clip 的总帧数。面板显示字符数和当前场景 FPS 对应的时长；不改变场景 FPS。
3. 单独设置姿势关键帧、根运动或手脚目标，再生成并检查动作。
4. 接受后，下一 Clip 使用这一段实际末姿作为起姿。不要给每段结尾都添加静止等待。

不要将说明书、Markdown 代码围栏、YAML、时间表或多段 Prompt 一起粘贴进生成文本。超过 1000 字符会报错。

## 动作复用、脚接触和接缝

选择已关联的动作文本、源 Action 和接收角色，再执行重新映射。防脚滑只用于合适的支撑区间；脚接触采用稳定的膝盖平面。

接缝可选择只修本段或前后均分。均分会成对备份相邻动作，重复执行可恢复/重算。如果要调整前面的接缝，先从后往前撤回相连修正。工具检测到人工修改会停止，避免覆盖它。

## 道具接触与动作检查

展开“道具接触与动作检查”，指定角色、道具、持握骨骼和开始/结束帧。开始帧先把道具放进手中，再烘焙持握。结束帧作为放下时刻，后续保持释放位置。

这个工具根据已有手部动作驱动道具。手腕目标、手指握姿和放下位置需要先调整好。它会拒绝覆盖已有动画、父级或约束的道具；恢复按钮只撤回本工具创建的动作。

“检查停顿与速度”输出手部/头部低速候选和速度峰值，不改动作或帧率。低速不一定要删除：扶碗、点头停留或情绪节拍可能有意义。

## 开发

`python tools/build_latest.py` 从当前扩展源码生成确定性 ZIP 和逐文件 SHA256 清单。安装包不含第三方插件、角色、场景或账号设置。

回归测试和限制见 `VALIDATION_0.10.0.md`。本目录其余研究与历史验证文档保留为背景材料，安装步骤以本页和 README 为准。
