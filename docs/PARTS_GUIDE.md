# 人物部件识别与分离（0.13.0）

入口：`N → BA 动画 → 人物部件识别与分离`。

这是本地候选识别功能，不调用图像 AI、网络服务或额外模型。综合材质/物体名称、静置位置、脚骨和头部骨骼权重、网格连接及近邻关系，提出服装、左右鞋、左右袜、下装、头发、身体和饰品分组。陌生材质或低把握的小配件保留为待识别/问号候选。

## 使用

1. 指定人物网格，或指定骨架以分析其可见蒙皮网格，点击“识别可拆分部件”。一次处理一个人物骨架。原网格不被切割、焊接或改材质。
2. 点击“彩色预览”。同色为同组；预览使用独立副本，不改变原材质，不参与正式渲染。再次点击关闭；卸载插件也会清理临时预览。
3. 检查鞋面/鞋底/鞋带是否同组，袜子、短裤、发带是否误混。列表名称可以修改，问号表示包含低把握的面。分组边界不等于身体覆盖完整性。
4. 选中列表中的一组，点击“选中此部件的面”。在编辑模式补选、取消误选后，选择“用选中面替换此部件”；未再选中的旧成员回到待识别。只想加入面时用“将选中面归入此部件”。也可新增自定义部件，把误选面转给身体或其他组。
5. 勾选需要拆出的部件，点击“分离勾选部件（保留原模型）”。默认勾选服装和左右鞋；袜子、下装等需自行勾选。未勾选部分作为完整剩余网格保存。
6. 结果位于“BA 分离部件”集合，各部件有自己的子集合。同一部件跨多个源网格时归入同一子集合，保留独立形态键系统，不强制焊接。可通过集合选择该部件的全部对象。
7. 原网格保留并隐藏，可用“切换原模型 / 分离结果”切回。正式渲染跟随所显示的版本。重新识别前会切回原模型，已有分离结果保留并隐藏，不自动删除用户编辑过的结果。另存工程后可继续使用分组和切换。

## 保留与检查

分离在副本中完成，逐部件对照静置顶点、全部相对形态键、UV、顶点权重、材质和骨架绑定，验证所有面恰好出现一次。原自定义法线按角点映射恢复；考虑 Blender 压缩存储精度，法线向量误差必须不超过 0.001（约 0.057°）。超限或其他验证失败则撤销本轮副本。

保留对象与形态键 Action、简单 NLA 片段、驱动；自引用驱动指向对应分离副本。源模型拓扑、坐标、材质名称/分配、骨架或权重变化后，旧分组不能直接用于分离，需要重新识别。不改场景 FPS、帧范围、骨架、物理参数或烘焙。

## 边界

- 支持局部 Z 轴竖直的人形模型。有常见左右脚骨名时据此判断左右，否则按局部 X 轴，需核对。非人形、横躺静置模型、全身共用无语义贴图、衣服只画在皮肤上时，不能保证自动识别。
- 袜子与长靴、头饰与兜帽、裙子与裤子、小金属配件仍可能误判，需要预览和人工修正；不能承诺任意模型零漏选。
- 当前分离支持骨架修改器、相对形态键与简单 NLA。活动的其他修改器、绝对形态键、复杂 NLA、游离顶点或已绑定的 SDEF 实时变形会明确停止。请在副本中处理后再拆分；SDEF 可在分离后重新绑定。
- 分离后继续使用原角色骨架。不会新建服装骨架、迁移刚体/关节到其他人物，也不会补出衣服下面原本不存在的身体。
- 不自动保存、发布或删除旧工程。临时彩色预览与正式分离结果用途不同，临时预览不应当作交付模型。

实现：`parts.py` 负责识别及事务分离；`parts_ui.py` 负责分组列表、预览、人工修正与结果切换。
