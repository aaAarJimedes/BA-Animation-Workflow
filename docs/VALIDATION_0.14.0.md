# BA Animation Workflow 0.14.0

本次重点是操作状态正确性、实际耗时及面板层级。没有改写已验证的动作重定向算法，也没有调整最终厨房工程或重新生成视频。

## 使用变化

N → BA 动画：顶部保留版本、实际 FPS、时间范围和可展开的组件诊断。

- 动作制作与镜头：原自动/分步入口移至独立折叠区，已有场景设置保留。
- 人物部件：识别后默认聚焦服装，显示勾选面数；人工归组仅在编辑模式可用，已有结果不允许重复分离。更换人物必须重新识别。
- 物理：选择角色、读取范围、检查、烘焙。高级参数默认收起；数值和原设置保留。
- 道具与交付：保持独立面板和原有操作入口。

## 性能

Blender 5.1.2，同一玛丽模型，独立后台进程；识别和依赖扫描取 3 次中位数，指纹取 5 次。结果是本机案例，不能推广为所有模型固定倍数。

| 操作 | 原版 | 优化后 | 耗时减少 |
| --- | ---: | ---: | ---: |
| 部件识别 | 0.803 秒 | 0.354 秒 | 56% |
| 模型指纹 | 0.170 秒 | 0.105 秒 | 39% |
| 1000 次组件状态查询 | 0.0340 秒 | 0.00442 秒 | 87% |

只缓存纯文本换行；骨骼分类仅在单次识别中复用。几何变化检查、全部形态键/UV/权重/法线检查及失败回滚仍执行。

## 验证

- workbench_optimization_test：旧指纹兼容、目标切换拦截、活动组边界、逐面复核状态、预览保留帧率范围、面板 RNA 属性/操作入口、重注册。
- parts_synthetic_test、parts_real_test：真实玛丽 65 形态键、原模型文件未变、共享数据与动作、失败回滚、多网格部件、保存重开、材质/UV/绑定及法线。
- finishing_test：道具接触、动作槽歧义回滚、分数帧率保持。
- physics_synthetic_test：MMD Tools 实际后台工作进程、两类物理骨骼、移动根、逐帧回放、恢复和分数帧率。
- delivery_assets_test、render_plan_test：媒体打包及失败恢复、负帧与源版本绑定、分段范围完整性。

界面已在真实 Blender 注册并检查绘制路径中的属性和操作入口。未调用云动作生成或全片重新渲染。

2026-09-13 补充桌面视觉验收：使用 Computer Use 操作本机 Blender 5.1.2，在默认窄侧栏发现并修正中文说明截断。重启后复查动作区说明换行、物理参数折叠、交付入口。打开玛丽人物，实际点击选择网格、识别、彩色预览、关闭预览；服装/头发/鞋袜分组显示，编辑归组按钮在物体模式禁用，关闭后原材质恢复。只在内存检查，未保存覆盖人物源文件。长对象名及个别长选项在窄栏仍会使用 Blender 标准省略显示，可悬停查看完整信息。

此轮没有通过界面执行收费生成、完整物理模拟或分离写盘；对应行为沿用上述后台回归证据。版本对应 Git 标签 `v0.14.0`。

安装验证：新启动的常规配置 Blender 加载 `bl_ext.user_default.ba_animation_workflow` 0.14.0；20 个安装文件与构建清单逐一一致。实际执行识别、彩色预览、关闭插件恢复原模型及再次注册均通过。上一安装保存在任务 Temp 的 `backups/before_workbench_0.14.0`。
