Blender 5.1.2 / MMD Tools 4.5.13，2026-09-08。

## 真实工程副本

- 53 个 MMD 刚体、39 个源关节、29 根物理骨骼，−30～778 共 809 帧。
- 检测到 29/29 个关节锚点支持同一个布局偏移；只在模拟副本校正。
- `fs.001` 在第 0 帧的相邻帧世界旋转从原缓存的约 80.39° 降至 2.72°，第 1 帧从 73.94° 降至 2.49°。
- 保留原工程 6 子步、10 次迭代；结果应用后与正帧连续模拟的最大矩阵元素差为 0.00000674。
- 原 Action 和所有非物理曲线不变，FPS、正式范围、负帧预览、原缓存范围不变。
- 真正启动并取消后台进程后，输入指纹完全一致，临时快照清理完成。
- 随机跳帧与顺序回放一致，保存重开后相同；原 Action 改名后仍可通过保存的指针恢复。
- 非有限结果与运行期间变更的输入被拒绝，不产生半次应用。

## 不含角色资产的合成模型

`physics_synthetic_test.py` 覆盖动态类型 1 / 2、移动及旋转的 MMD 根对象、使用 `frame` 的身体驱动器、30 / 1.001 FPS、−6～14 帧、未构建的物理状态和正常布局不被校正。测试明确断言根运动、驱动器和物理局部变换确实变化。结果映回原骨架后逐帧验证；注册、卸载、再次注册通过。遗漏预热、额外骨骼约束、重复应用和歧义布局被拒绝，失败后台任务不改输入。
