# MMD 物理与发丝跟随

## 区分三种状态

MMD 的刚体缓存烘焙、把求值结果写成视觉骨骼关键帧、烘焙后的艺术修饰是三层。检查当前 Action/slot、源动作元数据、刚体世界、物理跟随约束和缓存范围，不能仅凭按钮显示“已烘焙”认定最终头发由哪一层驱动。渲染过不等于烘焙过；物理关闭也可能是已烘焙骨骼避免双重驱动的正确状态。

重烘焙从保留的原始动作开始；不把已经烘焙并修饰的结果再次送进物理。用独立副本完成布局调整、顺序求值、验证及保存，再采用结果。烘焙后修饰记录输入动作/来源哈希和适用区间，避免重复叠加；模型刷新要保留正确动画骨架和这一状态链。

## 跨 0 帧与布局异常

先检查刚体/关节相对骨架的真实静置位置、单位/变换、碰撞层与排除对、初始穿透，再调整弹簧或求解精度。本案例源 PMX 物理整体偏离骨架，单纯增加子步没有修复根因。

Blender 5.1.2 本机最小复现证实跨 0 帧刚体点缓存缺少正常第 0 帧样本，可能使骨骼瞬间回初态。此结论限定于已测版本/缓存类型；用相邻帧求值和最小复現确认，不把所有第 0 帧异常都归为同一原因。

需要避开该问题时，在隔离工作副本把整个依赖链映射到正帧计算，完成连续模拟后视觉烘焙，并映射回原帧。动作、NLA、表情、物体、相机、约束影响和时间驱动表达式都需覆盖；不完整的映射先补全或明确阻止运行。保留原 FPS 和负帧预热语义，核对 -1/0/1 及所有已知异常区间。第 0 帧样本有效性比缓存记录总数更有意义。

## 头发碰撞与自然弯曲

上段僵硬、只有末梢弯折时，先看刚体类型和实际物理跟随：动画/静态跟随的发根不会因放大关节限角就变灵活。需要时释放合适发段的物理模式，让弯曲沿发链分担；保留有限扭转，不一口气放松整头发。

增加贴合躯干/肩颈的简洁碰撞体、以胶囊覆盖发段，可能减少漏碰；检查是否跟随正确骨骼、尺寸是否挤压发丝、碰撞组是否允许碰撞。柔软度、阻尼、弹簧和限角分别小步比较，变软不保证零穿模，过硬避让也可能把整束头发直着推到身后。

撩发应有沿链传播的弯曲、短暂跟手、释放和重力滑回；低头时保留自然垂落。艺术修饰优先分配到中段/末段，避免整束刚性旋转，也不要强迫头发必须越过肩后。看正式相机、辅助侧视角与连续帧；开放衣物包络距离只用于对照筛查，不能当精确穿模深度。
