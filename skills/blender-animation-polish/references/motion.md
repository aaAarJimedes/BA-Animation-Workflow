# 动作、连续性与预热

## 从实际表演提取动作清单

在正式相机下快速浏览全片，定位拼接边界、过长停顿和手/身体目的不明的区间。记录每个动作的开始、接触/重心变化、峰值、结束和下一段准备；保留原始 Action/NLA 与关键动作的可恢复副本。

“温柔、熟练、妈妈感”转成可观察的表演：肩膀放松、肘贴近身体、手有任务、重心轻微转移、视线先行、双手适当错相、整理后顺势进入下个动作。不是全程减速、每段加停顿，或随意塞入擦手动作。此项目的拍拍手是原片两个明确接触点，擦衣服是用户后来指定的新动作，两者不可互相替换。

为新生成 clip 保持一个主动作：搅拌、放下勺子、拍手整理、转身分别交付。动作自身的准备和收势不必拆散。每段给出起姿、肢体、轨迹、次数/速度、支撑或持物状态、末姿；上一段接受后的实际末姿是下一段手动锚点。局部帧范围 1–N 的可播放时长为 N / 有效 FPS；不要把 N−1 个插值间隔当作视频帧数。

## 衔接修复

1. 在修改前缓存整个相关区间及边界外若干帧的源变换，含躯干、颈头、四肢、手脚接触和道具。修改同一 Action 后继续从它采样会产生反馈；含小数帧键时尤其明显。
2. 同时检查局部与世界空间位移/旋转。头转向平滑不代表整体连续：上身跳动仍会移动头的位置。比较接缝前后多帧、支撑脚、手、皮肤网格和正式相机画面。
3. 对可自由过渡的轨迹使用带端点速度的短区间插值（例如 Hermite）。四元数先规范化并统一半球，处理最短旋转分支；不要直接平滑欧拉角跨界或把 q 与 −q 的分量差当作实际转动。
4. 保持接触的手/脚以世界目标补偿，再解回当前骨架。肘极向量要稳定，长轴最小旋转可以保留原滚转；不要每帧凭碰撞反馈把整条手臂重新推出去。
5. 把腕部扭转分配给适当的前臂/扭骨，尊重骨骼静置轴、骨长和可达范围。先减少不合理目标，再考虑角度限制；本案例的腕弯/扭转上限不能照搬到另一角色。
6. 只改被批准的部位和帧段，边缘平滑混合。保护拍手接触峰、脸旁/头发轨迹、原拥抱和支撑状态，核对未改区间。需要重采样时先缓存源姿态并移除目标区间旧键，再生成新键，防止小数帧旧键残留。

对停顿做局部时间重映射，而非全片统一提速。保存旧帧→新帧映射，审计和渲染使用同一映射。身体、表情、道具、相机物体/镜头数据、NLA 条带边界/影响和标记的时间关系都要核对；以 Action 身份去重，避免多个使用者导致重复重映射。

## 负帧预热

分别记录：正式输出起止帧、预览范围、Action 实际键与显示范围、刚体/布料等模拟缓存起止帧、模拟启用和已烘焙状态。正式输出常从正帧开始，但这不意味着删除负帧。

本案例通过预览范围保留 -30～778，身体关键帧包含负帧；最终正式出片为 0～778（779 帧），而早期 R4 曾从 1 开始。以本轮已确认的范围为准，不能从历史报告或缓存范围推导出片范围。遇到 Blender 属性范围限制，查询该版本实际边界，不写入后默认成功。

恢复预热时优先找原生成 Action 的真实初始过渡，平滑修正其末端使之接上当前正式首姿；检查负帧开始、结束和正式首帧之间的变化。复制首姿静止 30 帧是否合适取决于模拟初始化，不可代替已有的正确起始过渡。

原项目模拟关闭、缓存未烘焙时，如本轮只恢复区间就保持该状态。用户要求实际物理解算/烘焙时，按相关缓存类型从预热起点连续评估或重新烘焙并验证缓存有效性；修改影响模拟的动画/网格后不能继续把旧缓存当有效。说明“恢复预热区间”与“完成烘焙”的区别。
