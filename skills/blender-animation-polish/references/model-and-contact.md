# 人物换新、素材与接触

## 保留动画换人物

先分离问题来源：缺图/路径/颜色空间/透明混合、错误节点连接、法线/拓扑、权重或变形器。多次操作/保存本身不是“模型损伤”的证据。比较原 PMX 的静置顶点/骨架、同姿态求值网格和同光照材质；红块或折痕也可能来自纹理、色带/法线、重叠网格、权重和极端骨骼弯曲。模型换新是用户要求或证据支持的路径，不是每次材质异常都必须做的操作。

在隔离文件中用适用版本的 MMD Tools 导入原 PMX，或读取被指明的源 .blend。不要仅凭骨名相似就绑定：核对骨层级、静置矩阵、骨长/方向、缩放/坐标空间、必要扭骨与带权重的顶点组。A pose、T pose、不同 VRM/MMD 骨架可能并不兼容。

兼容时优先保留当前已验证的动画骨架，替换网格、材质和原始权重；重新指向 Armature 变形器，保留正确父级、父逆矩阵与世界变换。核对表达式/形态键名称、键值、Action slot、NLA、驱动和约束；仅复制 Action 名称不代表重新连接了表情。

不兼容时使用明确的重定向/修正静置姿态方案，在副本验证；不能声称动作逐字保持。旧人物放入不参与显示/渲染的备份集合，避免双重网格、刚体或影子；不要混用新旧骨架的物理控制链。重新打开最终工程检查纹理、共享 toon 图和外链资源。

仅在确认拓扑/法线确有问题时做局部修复。缝合重复顶点必须同时保护 UV、材质分区、顶点组和所有形态键；不要全角色自动焊接、重算法线或加细分。刷新前后静置顶点和骨架完全相同时如实说明，不能把“重新导入完成”说成“证明修好了损伤”。清掉经确认废弃的旧网格前，先核对实际渲染可见性、形态键/驱动和引用，保留必要恢复数据。

## 场景里的动作目的

按已有动作选择必要物品，核对尺寸、朝向和位置。抓握点应对应柄而不是道具原点；空闲手的支撑点、目光和身体方向要解释清楚。网络素材保留来源/许可与原包，验证下载文件；不把素材采集默认扩张成大规模采购或重做场景。

用真实接触状态组织动画：

| 状态 | 要成立的关系 |
|---|---|
| 持有 | 固定腕/掌到道具的抓握偏移；手指闭合、手腕方向自然 |
| 使用 | 道具路径与物体几何一致；支撑手/脚稳定 |
| 放置 | 在释放前达到可信支撑面，检查物体最低点与容器内壁 |
| 释放 | 先记录释放瞬间实际求值的世界矩阵，再切换约束/驱动或烘焙保持 |
| 撤手 | 道具留在支撑处，手短距离撤离并准备下个动作 |

切换 Child Of/父级/约束影响时检查切换两侧世界矩阵，不能只把 influence 改成 0。原骨架的扭骨和驱动可能让求解后的实际手腕不同于目标矩阵；必须更新求值再把抓握偏移应用到道具。

## 接触判定与自然度

先查看关键帧特写与正式画面，再用求值后的网格/BVH/射线筛查可疑区间。碰撞计数、最近面距离和有符号穿透深度不是同一件事。开放衣服、内外翻面和薄层会使最近三角形的有符号深度严重失真。

对身体前侧的擦衣/手掌接触，可沿已知接触方向投射到衣物前表面，并结合可见指尖、掌面和轮廓确认。一次失败的“6 cm 深度”读数在本案例实际只是薄层交叠，不能据此把双臂推开。

修严重穿模时局部、小幅、平滑地调整目标路径，保持自然肘部和手腕，不迭代追求零交叠。对真正的掌间拍手保留接近、轻触和分离节拍，避免两手相穿，也不要把动作抹平成双手抬起后停住。
